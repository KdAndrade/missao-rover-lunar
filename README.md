# Missão Rover Lunar 🚀

Este projeto contém um código simples em **Java** que simula a inicialização de um Rover espacial.  
O programa imprime mensagens de status, como sistemas iniciados, painéis solares e nível da bateria.

## Objetivo do Repositório

A intenção deste repositório é servir como **atividade prática** para exercitar:
- Criação de repositórios no GitHub
- Fluxo de branches (`develop` -> `main`)
- Realização de commits
- Criação e aprovação de Pull Requests (PR)

## Estrutura do Código

O código atual possui:
- Uma classe `Rover`
- Um método `inicializarRover()` que imprime mensagens de inicialização
- Um método `main()` que executa a inicialização
